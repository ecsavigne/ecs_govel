# Configuration
As configurations are at "<i><b>./gofiles/project_file</b><i>"
## Configurations for initial the container
- <b>PORT_IN_HOST</b>: Port in Host PC for service
- <b>CREATE_NETWORK</b>: true if want to criate network  
- <b>DOCKER_EXTERNAL_NETWORK</b>: Name network
- <b>IP_CONTAINER</b>: Ip container
- <b>SUBNET_CONTAINER</b>: Subnet exemple <strong>192.168.1.0/24</strong>
- <b>GATEWAY_CONTAINER</b>: Gatway example <strong>192.168.1.1</strong>
- <b>UPDATE_DEPENDENCIES</b>: true for update dependencies of golang project
- <b>SERVICE_NAME</b>
